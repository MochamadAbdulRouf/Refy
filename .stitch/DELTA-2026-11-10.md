## 2. Isi perubahan (yang penting)

### 2.1 Bottom nav didesain ulang jadi pil mengambang

Ini perubahan visual terbesar. Sebabnya ikut terlihat di snapshot: aset baru `image.png` adalah **gambar referensi tab bar glassmorphism** (gaya "iOS liquid glass") — tab aktif berupa kapsul menyala dengan halo, tab lain ikon outline redup. Nav model lama (`fixed bottom-0 w-full` … `backdrop-blur-xl`) diganti **pil mengambang** di 9 layar:

```
fixed bottom-4|5 inset-x-4 max-w-sm mx-auto h-[68px] rounded-full
bg-[#121621]/85  backdrop-blur-[30px]
border 1–1.5px solid rgba(255,255,255,.6)
shadow 0 12px 32px rgba(0,0,0,.65) + 0 0 12px rgba(255,255,255,.2)
```

Mini-player dinaikkan mengikuti nav: `bottom-16` → **`bottom-[88px]` … `bottom-[92px]`**, dengan kaca sendiri (`backdrop-blur(36px) saturate(180%)`, border `rgba(255,255,255,.15)`).

**Konsekuensi untuk `docs/DESIGN.md`:** tinggi nav tetap 68px (bukan 64px), nav tidak lagi menempel dasar (muncul 16–20px di atas dasar), blur nav berubah 24px → **30px**, dan warna nav bukan lagi `surface-container-lowest/90` melainkan **`#121621` pada 85 %**.
